JHE HAUL — PHASE I
AI SELLER INTELLIGENCE

Phase H is complete and verified.

Now begin Phase I.

This phase adds proactive seller intelligence to JHE Haul.

IMPORTANT:

Do NOT begin the full autonomous multi-agent system yet.

Do NOT allow AI to automatically change listings, prices, offers, or seller settings without explicit confirmation.

Do NOT invent analytics.

All seller intelligence must use REAL JHE Haul marketplace data.

==================================================
PHASE I OBJECTIVE
==================================================

Build an AI Seller Intelligence layer that helps sellers understand:

- how their listings are performing
- which listings need attention
- whether buyers are engaging
- whether offers/messages are being missed
- which listings may need improvement
- when listings are getting old or stale
- which listings are performing best

The seller should receive useful recommendations based on real activity.

==================================================
1. SELLER INTELLIGENCE DASHBOARD
==================================================

Add an AI-powered section to the existing dedicated Seller Dashboard.

Suggested heading:

Seller Insights

or

AI Seller Insights

Do NOT replace the existing dashboard.

Add intelligence to it.

==================================================
2. REAL DATA ONLY
==================================================

Use actual seller data such as:

- listing views
- active listings
- offers received
- unread messages
- listing age
- sold listings
- listing completeness
- price
- photo count
- video availability
- delivery availability
- category
- recent engagement

Do NOT create fake numbers.

Do NOT create fake performance history.

==================================================
3. PRIORITY INSIGHTS
==================================================

Surface the most useful issues first.

Examples:

“Your Chevrolet Volt has 87 views but no offers.”

“You have 3 unanswered buyer messages.”

“Your listing has been active for 21 days.”

“This listing has fewer photos than your other listings.”

“This listing is receiving more views than your other vehicles.”

“Your listing has 4 pending offers.”

Use only actual supported facts.

==================================================
5. LISTING PERFORMANCE ANALYSIS
==================================================

Analyze each seller-owned listing using available metrics.

Potential performance dimensions:

- views
- inquiries
- offers
- listing age
- sold conversion
- completeness
- photos
- video
- price changes
- delivery availability

Do not claim causation without evidence.

Example:

Good:
“This listing has 120 views and no offers.”

Avoid:
“Your price is definitely too high.”

Instead suggest:

“You may want to review the price or listing details.”

==================================================
6. AI RECOMMENDATIONS
==================================================

Provide suggestions such as:

- Add more photos
- Add a video
- Add missing vehicle mileage
- Improve description
- Clarify condition
- Review price
- Enable JHE Haul delivery
- Respond to messages
- Review pending offers
- Relist/renew
- Mark sold if item is no longer available

Do not automatically apply changes.

==================================================
7. PRICE RECOMMENDATIONS
==================================================

Do NOT create unsupported market-value claims.

If real comparable listing data exists inside JHE Haul, AI may say:

“Similar JHE Haul listings are generally priced between X and Y.”

Only if sufficient comparable data exists.

If not enough data exists:

Do not invent a market price.

Instead say:

“JHE Haul does not yet have enough comparable listings to estimate a reliable price.”
