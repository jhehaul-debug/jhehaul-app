3. Add a Pending Sale Status

The seller currently has listing status options such as:

Active | Sold | Reserved

Add another option:

Pending

Pending means the seller has a potential buyer and the sale is currently being completed, but the item has NOT officially sold yet.

Pending behavior

When a seller marks a listing Pending:

* Display a clear Pending badge on the listing.
* Keep the listing visible to marketplace users.
* Clearly indicate that the sale is currently pending.
* Do NOT automatically mark the listing Sold.
* Allow the seller to change Pending → Sold when the transaction is completed.
* Allow the seller to change Pending → Active if the sale falls through.
* Seller must still be able to edit the listing while it is Pending.

The seller should have these listing statuses available:

Active | Reserved | Pending | Sold

Do NOT force the seller to follow a particular sequence. The seller should be able to select whichever status accurately represents the listing.

Make sure Pending works for ALL marketplace categories, not just vehicles.

Update Pending everywhere necessary, including:

* Database/status validation
* Backend/API
* Seller listing controls
* Listing cards
* Listing detail pages
* Browse/Search
* Account/My Listings
* Admin area

Do not break existing Active, Reserved, or Sold listings.
