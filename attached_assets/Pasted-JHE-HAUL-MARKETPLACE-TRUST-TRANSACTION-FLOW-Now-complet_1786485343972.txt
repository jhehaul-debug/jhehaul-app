1. SELLER PROFILES

Every marketplace seller should have a public seller profile showing:

- Profile picture
- First name or display name
- City, MN
- Member since
- Active listings
- Sold listings count if appropriate
- Basic trust information

Do NOT publicly show:
- phone number
- email
- exact street address

Add:
“View Seller Profile”

2. FAVORITES / SAVED ITEMS

Make sure logged-in users can:

- Save a listing
- Remove from saved
- View all Saved Items from Account

Use a heart/save icon on listing cards and listing detail pages.

3. OFFERS

For ordinary marketplace items, add:

“Make Offer”

Offer flow should allow:
- Offer amount
- Optional message

Seller should be able to:
- Accept
- Decline
- Counteroffer

Buyer should be able to:
- Accept counteroffer
- Decline counteroffer
- Withdraw an open offer

Use marketplace language:
Offer
Counteroffer
Accepted
Declined

Do NOT use Quote or Bid for ordinary marketplace items.

4. LISTING STATUS

Marketplace item statuses:

- Active
- Pending
- Sold
- Removed

Seller can mark:
Pending
Sold

When an offer is accepted, allow the seller to optionally mark the listing Pending.

Once transaction is completed, seller can mark Sold.

Sold listings should no longer appear as actively available but may remain visible as Sold if appropriate.

5. MESSAGING

Tie marketplace messages to the relevant listing when possible.

Show:
Listing title
Listing photo
Buyer
Seller

Do not expose personal contact information publicly.

6. DELIVERY CONNECTION

If an item listing supports delivery, show:

🚚 Need Delivery?

After a buyer/seller reaches an agreement, make it easy to open the existing Schedule Delivery flow.

Automatically attach:
- listing
- item photo
- buyer
- seller

Do not make users re-enter data already known.

7. REPORTING & SAFETY

Report Listing
Report User

- Scam/Fraud

- Other

Reports must appear in Admin.
