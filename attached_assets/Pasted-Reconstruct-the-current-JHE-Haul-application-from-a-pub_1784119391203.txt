Reconstruct the current JHE Haul application from a public marketplace into a private customer portal for JHE Haul.

IMPORTANT:
Do NOT rebuild the application from scratch.
Do NOT remove or break any working functionality unless it is specifically being replaced.
Keep the current database whenever possible.
Keep Google OAuth, Stripe, DigitalOcean deployment, authentication, photo uploads, admin accounts, and customer accounts working.

========================
NEW APPLICATION PURPOSE

The application is no longer a marketplace.

Customers submit service requests directly to JHE Haul.

Only JHE Haul administrators can review requests, prepare quotes, schedule jobs, and complete work.

There are NO public haulers.

========================
REMOVE OR DISABLE

Remove public access to:

• Hauler registration
• Hauler login
• Hauler dashboard
• Bid submission
• Accept Bid workflow
• Hauler invitations
• Hauler profile pages
• Hauler search
• Public bidding

Do not delete database tables unless absolutely necessary.
Hide or disable these features.
