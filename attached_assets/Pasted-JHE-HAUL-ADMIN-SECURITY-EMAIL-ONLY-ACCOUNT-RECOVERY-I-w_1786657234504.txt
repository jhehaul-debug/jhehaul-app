==================================================
1. ADMIN FORGOT PASSWORD
==================================================

Add a "Forgot Password?" option to the ADMIN login.

When used:

1. Admin enters the primary admin email.
2. Generate a cryptographically secure, single-use password-reset token.
3. Email a password-reset link.
4. Token must expire after a short period, preferably 15–30 minutes.
5. Once used, the token must immediately become invalid.
6. Never send the existing password by email.
7. Passwords must remain securely hashed.

After successful password reset:
- invalidate the reset token
- invalidate existing admin sessions where appropriate
- send an email notifying the admin that the password was changed

2. ADMIN RECOVERY EMAIL
==================================================

Add a separate:

Recovery Email

field for the ADMIN account.

This must be different from simply displaying an email on the profile.

The recovery email should be stored securely and used for account recovery/security purposes.

When a recovery email is added or changed:

1. Send a verification email to the new recovery address.
2. Do NOT activate it until the verification link is clicked.
3. Send a security notice to the existing/primary admin email that the recovery email was changed.
4. Require the current admin password before changing the recovery email.

Do not display the complete recovery email publicly.

Example display:

j*****@example.com
