MODEL FIELD

After selecting Make, allow seller to select or enter the Model.

Where practical, make the Model field dependent on the selected Make.

Example:

Toyota
→ Camry
→ Corolla
→ Highlander
→ RAV4
→ Tacoma
→ Tundra
→ etc.

Ford
→ F-150
→ Explorer
→ Escape
→ Mustang
→ Bronco
→ etc.

Do NOT hard-code the system in a way that makes maintaining every vehicle model difficult.

A searchable model field with manual fallback is acceptable.

========================================
TITLE GENERATION

Use the vehicle fields to help automatically create the listing title.

Example:

Year: 2018
Make: Toyota
Model: Camry
Trim: SE

Suggested title:

2018 Toyota Camry SE

Allow seller to edit the title before publishing.

Do not overwrite a seller-edited title without permission.

========================================
MOBILE DESIGN

Keep the vehicle form simple.

Do not display all advanced fields at once if it makes the page too long.

Required primary vehicle fields should be:

Year
Make
Model
Mileage

Optional vehicle details can be placed under:

“More Vehicle Details”

========================================
DO NOT BREAK

Do not break the normal marketplace listing flow.

Non-vehicle listings should continue using the regular:

Title
Description
Category
Condition

fields.

Vehicle-specific fields should only appear when the selected category is Vehicles.
