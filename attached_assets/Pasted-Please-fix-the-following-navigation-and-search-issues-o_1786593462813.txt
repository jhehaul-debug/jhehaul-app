Please fix the following navigation and search issues on the LIVE JHE Haul Marketplace.

1. Remove Browse Marketplace From the Messages Page

The My Messages page still shows a Browse Marketplace button.

Remove it.

The Messages page should be dedicated to the user’s conversations.

When there are no conversations, show only:

💬 No conversations yet

When you contact a seller or a buyer messages you about your listing, your conversations will appear here.

Do NOT show:

* Browse Marketplace button
* Sell Something link
* Extra marketplace navigation inside the Messages page

The permanent bottom navigation already contains:

Home | Browse | Sell | Messages | Account

That is enough.

When conversations exist, this page should display the conversation list and allow users to open and reply to messages.

⸻

2. Fix the Marketplace Search Button

The main marketplace Search button currently does not navigate/search correctly.

Make it functional.

When a user enters a search and presses Search, it should:

* Search active marketplace listings
* Take the user to the search results
* Preserve the search term
* Show matching listings
* Show a clear “No results found” state when nothing matches

Search should work with:

* Listing title
* Make/model for vehicles
* Category
* Description
* City/location where appropriate
* Common keywords

Pressing Enter/Return from the search field should perform the same search.

⸻

Make Browse All take the user to the full marketplace listing page showing all active listings.
